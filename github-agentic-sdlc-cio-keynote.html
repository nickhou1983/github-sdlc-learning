1. 痛点与破局 · 为什么单模型静态路由不够用？ Dynamic Signal Routing
打破“全用旗舰模型太贵、全用小模型太笨”的两难

传统静态路由缺陷：仅靠初始 Prompt 长度猜测难度，无法感知多步编码中的真实阻碍。
运行时信号感知：实时采集 AST 复杂度、跨文件引用深度与测试报错，在任务执行中动态切换拓扑。

2. 模式详解 · Single 直达与 Cascade 级联升级 Confidence Gate & Escalation
80% 常规步骤用轻量模型起草，遇难自动平滑升级

Single（直达）：代码定位、常规 CRUD 与单测脚手架直接交由低延迟、低成本模型秒级完成。
Cascade（级联）：内置验证门禁实时评估草稿质量；一旦置信度不足或单测挂掉，无缝升级前沿大模型接管。

3. 模式详解 · Critique 跨模型家族交叉互评 Cross-Family Critic Loop
打破同源模型思维盲区，架构级难题异构对抗把关

异构模型配对：主模型生成方案后，自动调度不同厂商/家族的模型担任独立 Critic（审查官）。
对抗挑刺修正：专门排查并发死锁、边界遗漏与安全漏洞，主模型吸收反馈修正后再输出终稿。

4. 治理闭环 · GitHub Models 评测场与 Agent FinOps Cost per Merged PR Optimization
用真实仓库基准评测选型，将算力精准花在刀刃上

GitHub Models Evals：基于本团队真实历史 Issue/PR 回放评测，科学量化各模型组合的质量与成本。
单 PR 成本最优：把高昂推理算力集中在架构规划（Plan）与疑难攻坚，显著压降单 PR 综合算力成本。

核心价值：HydraFusion 不是简单的模型切换开关，而是内置于 Agent Harness 的多模型协同与算力 FinOps 引擎。
