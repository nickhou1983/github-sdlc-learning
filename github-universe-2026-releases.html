02. Copilot Projects：围绕业务目标协调跨仓并行工作

真实工作往往跨越多个仓库甚至无需代码库。给 Copilot 设定一个持续性目标（Goal），由它自动拉起并行会话、沉淀产物并按周期复盘。
COPILOT PROJECT OVERVIEW BOARD · 跨仓库并行会话状态分组与实时引导 (Steer)
支持绑定多个 Repos 或 0 Repo 纯研究/规划项目
1. NEEDS INPUT 优先处理
需人工拍板与授权
集中展示阻塞在架构选择、Plan 审批或权限请求的会话，一键回复继续推进。
2. OPEN (PR READY) +342 / -89
已生成待审 PR
直观显示每个会话关联的跨仓 Pull Request 状态、增删行数与审查进度。
3. WORKING Parallel Agents
后台并行执行中
按需并发运行多个子智能体；随时点击任意会话通过 Steer this session 插话纠偏。
4. DONE Archived to Library
已完成与产物沉淀
完成的代码合并与调研报告自动归档，作为后续迭代任务的历史上下文。
A
GOAL-DRIVEN ORCHESTRATION
目标驱动与跨仓/无仓灵活建项

告别“一个仓库开一个孤立窗口”的碎片化管理。

跨多仓库协同：在创建 Project 时可添加多个关联前后端/微服务仓库，统一推进大特性。
无仓库纯知识工作：支持不添加任何仓库，专门用于分析客户反馈、输出竞品报告或制定产品发布计划。
B
PROJECT LIBRARY (USER + AGENT)
专属资料库（Library）双向沉淀

把输入背景资料与智能体输出成果物集中管理。

User 资料区：上传 PRD 规格文档、设计会议纪要、客户原始反馈文件或文件夹，供所有会话引用。
Agent 产物区：智能体在各会话中生成的主题聚类报告、架构对比方案自动保存在 All Files > Agent 下。
C
RECURRING PROJECT WORK
自然语言设定项目级周期自动化

直接在项目对话中吩咐定时执行的长期例行任务。

一句话创建定时任务：如“每周一早 9 点汇总本周新增客户反馈并按主题分类”，自动注册到项目的 Automations 标签页。
对话式动态调整：随时在对话中要求修改执行时间或分析重点，也可在面板中手动暂停、编辑或删除。
适用边界建议：单仓库明确开发任务可直接从该 Repo 发起 Session；跨多仓特性、长期专项调研或周期性复盘建议使用 Copilot Projects。

03. Copilot Fusion：多模型智能路由与运行时编排 (GA)

开发者只需选择投入级别（Standard / High / Max），Copilot Fusion 根据任务推理、编码、调试与工具调用复杂度，在单模型或多模型组合间自动路由。
THREE RUNTIME EXECUTION PATTERNS PER-PROMPT DYNAMIC ROUTING
三大运行时执行模式（同一会话内按每条 Prompt 动态切换）

结合实时模型健康度与自然缓存边界（Cache Boundaries）智能选路，简单任务绝不浪费额外 Credits。

1. Single（单模型直出）：
针对日常明确指令，直接匹配最适合的单一模型一次性完成任务，零额外评审延迟与费用。
2. Cascade（级联起草 + 裁判升级）：
先由高性价比模型快速起草方案，再由独立的裁判模型（Judge）审查质量；若达标则直接采纳，若存在缺陷则自动升级（Escalate）至更强推理模型重写。
3. Critique（多模型并行挑错评审 + 汇总修正）：
一个主模型起草响应，多个异构模型在后台并行独立评审挑错（Critique），系统汇总各方反馈后交由原模型迭代修正，仅向用户展示最终打磨后的高质量结果（悬停可查看参与模型列表）。
端侧本地模型自动路由（Public Preview）：在 Fusion Standard 档位下，若本地安装了 MAI Code 1.1 Flash（Windows）或通过 Ollama 运行 Qwen3.8 Flash Next（Win/macOS/Linux），开启实验开关后 Fusion 会优先调度本地模型以节省额度并降低延迟。

评测表现逼近顶尖单模型（分差 < 2 分），成本减半、耗时缩短 40%

EFFORT LEVELS MATRIX GA in VS Code · CLI · Copilot App · JetBrains
Fusion Standard（日常均衡）：平衡成本、质量与响应速度，每次为任务挑选最合适的单个模型（支持路由至本地 Flash 模型）。
Fusion High（高阶编排）：面向跨多文件修改或复杂 Bug 定位，适度引入额外模型验证调用，兼顾准确率与 Token 节省。
Fusion Max（前沿极限推理）：调动最强模型池与 Critique/Cascade 模式，攻克最深层的架构重构与疑难杂症。
Fusion Fast（极速内联）：系统自动在 VS Code Inline Chat 等强低延迟场景内部调用（无需用户手动选择）。
告别模型选择困难症：把“选哪个模型”交给运行时路由器，开发者只需按任务重要程度调整 Standard / High / Max 档位。

04. Copilot Automations & Agentic Workflows (GA)

将可复用的 Prompt、事件触发器与受控工具集封装为云端自动化任务，并具备从运行结果中自我学习并提出改进建议的能力。
01
TRIGGERS & GUARDRAILS
多元触发器与防注入安全边界

在 GitHub 仓库 Agents 页、Copilot App、VS Code（v1.144+）或 REST API 统一创建与管理。

三大触发方式：定时调度（Hourly / Daily / Weekly）、仓库事件（Issue 创建、PR 打开或新 Commit 同步）及 REST API 外部调用（支持传入动态上下文）。
精准过滤条件：支持配置搜索查询过滤器（Search Query）与 PR 变更文件路径过滤，仅在匹配的事件上启动 Cloud Agent。
默认防 Prompt 注入：默认忽略无仓库写权限（Write access）用户触发的事件，防止外部不可信用户通过提 Issue 诱导智能体越权操作。
最小权限工具勾选：精确勾选允许调用的 GitHub 原生工具或外部 MCP Server 工具，支持一键 Suggest tools 智能推荐与 AI Credits 消费上限控制。
02
PERSONAL vs SHARED MODE
个人（Personal）与团队共享（Shared）双模式

针对个人效率与团队公共工程流水线提供清晰的权限、身份与计费隔离（仅限私有/内部仓库）。

可见性与编辑权：Personal 仅创建者自己可见可改（运行记录全仓可读）；Shared 对全仓只读成员可见、所有拥有 Write 权限的成员均可协同编辑维护。
执行身份（Identity）：Personal 以创建者个人账号身份执行 GitHub 操作；Shared 以独立的 Copilot 官方身份执行，创建者离职或权限变更不会导致流水线中断。
计费归属（Billing）：每次运行消耗 GitHub AI Credits 与 Actions 分钟数；Personal 计入个人额度，Shared 统一计入仓库所属组织或企业账单。
自动继承仓库配置：无缝继承目标仓库的 Custom Instructions、Agent Skills、Firewall 规则以及云端 Secrets 与环境变量。
03
CONTINUOUS LEARNING ENGINE
自进化学习引擎 & Agentic Workflows 开源 GA

让自动化不仅能执行任务，还能根据执行结果持续演进迭代。

Automation Groups 自优化：将相关联的多个 Automation 编入同一群组共享上下文；系统会根据历史运行结果与人类反馈，自动生成针对 Prompt 和流程的改进提案供开发者审批。
典型高价值场景：新 Issue 自动复现 Bug、PR 就绪时自动启动浏览器截图并挂载评论、监控告警触发生产事故初步根因排查。
GitHub Agentic Workflows (GA)：源自 GitHub Next 的开源项目正式全面可用，支持以声明式方式在 Actions 中自动化处理 Issue 分诊、CI 失败分析与文档同步更新。
核心进化：传统 CI/CD 只能运行确定性脚本；Copilot Automations 让仓库具备了可共享、受权限约束且越用越聪明的推理型流水线。

UPDATE #11 · SECURITY EXTENSION (PUBLIC PREVIEW) SECURITY CANVAS
Security Extension：在 Copilot App 内一站式审查与修复告警

无需在浏览器 github.com 告警页与本地编辑器之间来回切换，在专属 Security Canvas（安全画布） 中同时检视存量告警与本地增量代码。

存量 Code Scanning 告警闭环：按严重程度浏览、搜索与筛选仓库告警；选中单条或多条告警即可让 Copilot Explain（解释成因） 或 Fix（生成修复）。修复仅写入本地工作区，不自动 Commit/Push，由开发者审阅确认。
提交前主动运行 /security-review：在发起 PR 前对本地未提交变更运行安全审查，新发现的风险与存量告警同屏展示；当本地代码再次改动时自动提醒重新复查。
防重工与审批流集成：直观展示告警已关联的 PR（避免多人重复修同一漏洞）；支持直接 Dismiss 告警并无缝对接企业的 Delegated Alert Dismissal 审批流。
一键安装命令：终端执行 copilot plugin install github-security@awesome-copilot 或在 App 的 Customize 中搜索 github-security 安装（浏览与忽略告警不消耗 AI Credits）。
UPDATE #12 · AI SCAN FOR REPOSITORIES (PUBLIC PREVIEW) BEYOND CODEQL & PR DIFFS
AI Scan for Repositories：覆盖任意语言的全仓智能体漏洞猎手

从仅扫描 PR 增量变更扩展至全仓库默认分支最新 Commit 的按需扫描，发现静态规则难以捕捉的复杂漏洞。

突破语言与静态规则限制：既能扫描 CodeQL 尚未支持的编程语言与框架，也能在 CodeQL 已支持的语言中利用 Agentic 探索能力挖掘跨文件业务逻辑漏洞。
智能去重与固定成本预算：每个扫描任务在固定时间预算（Fixed time budget）内聚焦高风险代码区域，确保费用可控；与 CodeQL 同开时自动跳过 CodeQL 已报告的问题。
无缝融入现有安全工作流：结果直接汇入 GitHub Code Scanning 告警列表，支持指派责任人、加入 Security Campaigns 或一键派发给 Agentic Autofix 批量修复（合并修复后重新触发扫描即可核验关闭）。
无需 Copilot 席位许可证：面向所有公共仓库及开启了 GitHub Code Security / Advanced Security 的企业私有/内部仓库开放，按 Code Security AI Credits 计费并支持设置 SKU 级预算上限。
双剑合璧：编码阶段用 Security Extension 实时运行 /security-review 拦截增量风险；存量代码库用 AI Scan 深度清扫历史死角。

PART 03 · SECRET & SUPPLY CHAIN DEFENSE UPDATES #13 & #14 · PUSH PROTECTION & PACKAGE FIREWALL
SLIDE 10 / 12

13 & 14. AI 密钥推送拦截与软件供应链防火墙

当 AI 智能体自主编写代码并安装第三方依赖包时，必须拦截无固定格式的自定义凭据泄露与恶意依赖包投毒，并消除无效漏洞噪音。
13
AI SECRET PUSH PROTECTION
Push Protection AI 密钥检测：拦截正则漏掉的非结构化机密

传统密钥扫描依赖固定前缀（如 ghp_、AKIA）和正则表达式，难以识别高熵自定义密码或内部私有凭据。

remote: — PUSH PROTECTION —
remote: AI Secret Detection blocked unstructured password in config/db.env:14
AI 语义与上下文识别：利用 AI 模型在 git push 阶段实时识别无固定格式的密码、连接串与非结构化机密（Unstructured secrets）。
人机代码双重守护：无论是人类开发者手写还是 AI 智能体自动生成的代码，均在推送入库前被强制阻断（需同时开启 Push Protection 与 AI Secret Detection）。
14A
PACKAGE FIREWALL
Package Firewall：在安装前阻断恶意与高风险 npm 包

将供应链安全从事后发告警前移至包管理器下载安装的那一刻，防止投毒脚本执行。

[Blocked Targets]
• AI Coding Agents (Cloud / Local)
• GitHub Actions CI Runners
• Developer Local IDEs
事前主动拦截：当 AI 智能体、CI 构建 Runner 或开发者本地 IDE 尝试安装恶意（Malicious）或高风险 npm 软件包时，防火墙直接阻断下载。
防范幻觉包与供应链投毒：有效防止智能体在自主装包时引入恶意抢注包或被劫持版本。
14B
REACHABILITY ANALYSIS
Reachability Analysis：函数级调用可达性分析，只修真正有风险的漏洞

解决依赖树中成百上千条 Dependabot 告警不知从何修起的痛点。

Dependency CVE-2026-XXXX
↳ Vulnerable fn: parseUnsafeXml()
↳ Call Path Detected in src/ingest.js:88
精准识别真实调用路径：深度分析你的 JavaScript 业务代码是否真正直接或间接调用了第三方依赖包中含有漏洞的具体函数。
大幅降噪聚焦高优修复：把真正可被触发的漏洞置顶处理，避免团队在从未被调用的死代码依赖升级上浪费精力。
三位一体供应链防线：入库前用 AI Push Protection 锁死机密 → 装包时用 Package Firewall 拒止投毒 → 修复时用 Reachability Analysis 精准排优。
